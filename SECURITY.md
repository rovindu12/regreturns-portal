# Security policy

This is a portfolio project with fictional data. If you find a vulnerability, please report it privately through
GitHub's "Report a vulnerability" (Security tab) rather than opening a public issue. Include the steps to reproduce
and what an attacker gains. You can expect an acknowledgement within a week.

Only the latest commit on `main` is supported. The threat model, the controls and how they are tested are in
[docs/SECURITY.md](docs/SECURITY.md).
